# Dodge the Creeps! — Godot 4.7.2

Completed the **Your first 2D game** (Dodge the Creeps!) tutorial in GDScript.
Built for **Godot 4.7 / 4.7.2 stable**, with the **original course-provided**
`dodge_the_creeps_2d_assets.zip` art, Xolonium font, music, and game-over sound.

## Run on Windows 11

1. Install **Godot 4.7.2 stable (standard, not .NET)** from https://godotengine.org/download/archive/4.7.2-stable/ .
2. Open Godot Project Manager > **Import**, select this folder's `project.godot`.
3. In the Godot editor, press **F5** to start the finished game.
4. Click **Start** (or press Enter / Space), then move with arrow keys or WASD.
5. Avoid creeps. The score increases every second. Click Start again after a hit.
